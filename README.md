## ⚙️ Run Locally

Follow these steps to run the portfolio on your computer.

**1. Clone the repository**

```bash
git clone https://github.com/sabavathajay93-ship-it/ajay-portfolio.git
```

**2. Navigate to the project folder**

```bash
cd ajay-portfolio
```

**3. Open the website**

Open `index.html` directly in your browser.

Alternatively, use the **Live Server** extension in Visual Studio Code for local development.

No additional dependencies or build tools are required.

## 🌐 Deployment

This portfolio is hosted using **GitHub Pages**.

To deploy your own version:

1. Upload the project files to a GitHub repository.
2. Open the repository on GitHub.
3. Navigate to **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder.
6. Click **Save**.

Your website will be published using the GitHub Pages URL.
